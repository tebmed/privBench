# Dart and Flutter for the development of Android applications

Dart and Flutter, developed by Google, are experiencing remarkable growth, drawing in more developers with their cross-platform capabilities, performance, and contemporary design approach. Their popularity is on the rise, with approximately 42% of developers utilizing them in 2023, as reported by a Statista survey [1]. The test cases contained in this folder represent both benign and vulnerable Android apps performing API calls to the Android framework using the Dart programming language. The vulnerable cases highlight instances where apps possess excessive privileges, utilizing more permissions than necessary.
