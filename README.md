# Privbench
**Privbench** is a Benchmark of open-source Android applications capturing vulnerabilities related to privilege escalation attacks in Android ecosystem. It enables comprehensive evaluations of static code analyzers, including IDE plugins.  **Privbench**  focuses specifically on privilege escalation vulnerabilities. For each  identified vulnerability,  Privbench  provides detailed documentation  demonstrating its potential presence within real-world application code. Additionally, the benchmark showcases how these vulnerabilities can be exploited by malicious applications. It also specifies  the vulnerable Android API versions, offering insights into potential exploit targets. The core aspect of  Privbench  lies in providing  diverse code patterns that manifest the same vulnerability, catering  to both Java, Kotlin and C/C++ native programming languages.  This diversity facilitates a thorough evaluation of existing security code analysis tools in detecting known privilege escalation vulnerabilities within the Android ecosystem.
