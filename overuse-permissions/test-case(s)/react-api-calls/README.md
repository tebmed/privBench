# React-Native for the development of Android applications

React Native, backed by Facebook, is witnessing substantial expansion, attracting a growing number of developers with its cross-platform functionality, performance optimization, and modern development paradigm. Its adoption rate is soaring, with around 38% of developers leveraging it in 2023, according to a Statista survey [1]. The test scenarios enclosed in this directory illustrate both benign and vulnerable Android applications executing API requests through the React Native framework. The vulnerable scenarios underscore instances where apps exhibit over-permissioning, accessing more permissions than essential for their intended functionality.
