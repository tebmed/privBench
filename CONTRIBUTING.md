# Contributing

Contributions are **welcome**.

## Pull Requests
 
 - Please adhere to the same format as the already implemented vulnerabilities,
 - Explicitly mention the CVE number for each vulnerability in both the readme file and the pull request,
 - Provide a detailed description of the vulnerability in the readme file, including: a short description, key concepts to understand the vulnerability, and a detailed attack scenario.
 - Include screenshots illustrating the scenario.
 - Attach APK files of the relevant applications.
 - Specify the API version(s) where the vulnerability is exploitable.
